## 📋 О проекте

NeuroCT Consultant - это интеллектуальная система поддержки принятия врачебных решений, созданная для помощи неврологам в интерпретации результатов компьютерной томографии и получения экспертных консультаций от виртуального эндоваскулярного хирурга.

### 🎯 Основная цель
Упростить и ускорить процесс диагностики сосудистых патологий головного мозга, предоставляя мгновенный доступ к экспертной оценке результатов КТ-ангиографии.

## 🏗️ Архитектура системы

- **Интеграция с Yandex AI Studio** через neurofw Workflow и nerogw Gateway!!!

```
graph TB
    A[Невролог] --> B[Терминал/Telegram Bot]
    B --> C[NeuroCT Consultant]
    C --> D[Yandex AI Studio]
    C --> E[MCP Server]
    E --> F[Фейковый КТ-генератор]
    F --> G[Yandex Storage]
    G --> H[📄 Заключение КТ по URL]
    H --> D
    D --> I[🎯 Экспертная консультация]
    I --> A
```

## 🚀 Быстрый старт

### Предварительные требования
- Go 1.21 или выше
- Аккаунт в Yandex Cloud
- Доступ к Yandex AI Studio

### Установка и запуск

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/your-username/neuroct-consultant.git
cd neuroct-consultant
```

2. **Настройте окружение**
```bash
cp .env.example .env
# Заполните .env файл вашими данными:
# YANDEX_API_KEY=your_api_key
# YANDEX_FOLDER_ID=your_folder_id
# STORAGE_BUCKET=your_bucket_name
```

3. **Запустите приложение**
```bash
go run main.go
```
